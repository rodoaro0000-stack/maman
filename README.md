# Anniversaire de Maman ✨

Expérience web (HTML/CSS/JS) : lumière → enveloppe → message → souvenirs → lettre → finale.

## Personnaliser (dans `script.js`)
- `MEMORIES` : ajoute tes photos dans `photos/` puis renseigne `src: 'photos/ma-photo.jpg'` et la légende.
- `LETTER` : le texte de la lettre.

## Publier
GitHub Pages : branche `main`, dossier `/ (root)`. Vérifie les droits de la musique avant publication publique.
